为什么鹈鹕喊的是 21？

题目说明，圆形和五角星形可以靠手感分辨。据此按形状选择，最少取出 21 个：9 个圆形 + 12 个五角星形。

形状 / 口味苹果味桃子味西瓜味
圆形798
五角星形764

12 个五角星形中：没有苹果味时最多只有 6 + 4 = 10 个，没有桃子味时最多只有 7 + 4 = 11 个，因此必定同时有苹果味和桃子味。9 个圆形中，西瓜味最多 8 个，必定至少有一个苹果味或桃子味，恰好能与另一口味的五角星形配成一对。

20 个不能保证：记圆形取 c 个、五角星形取 s 个，且 c + s ≤ 20。若 c ≤ 8，圆形可以全是西瓜味；若 s ≤ 4，五角星形可以全是西瓜味。其余情况 c ≥ 9、s ≥ 5，此时 c ≤ 15、s ≤ 11，仍可能全部取自苹果味和西瓜味（这两味共有 15 个圆形、11 个五角星形），没有桃子味。因此 21 是最小值。

题意区别：如果规则禁止按手感挑选形状，要求完全随机盲取，则需 29 个。画面采用题目明确给出的“形状可辨”条件，答案为 21。
